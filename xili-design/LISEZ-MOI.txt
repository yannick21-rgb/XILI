Police Lyl Bah Demo — CE QU'IL FAUT SAVOIR
------------------------------------------

Licence : « Free For Personal Use » (1001Fonts). Usage commercial interdit
sans autorisation écrite. Embarquement dans une application seulement si
l'application est un usage personnel ET ne distribue pas la police.

Version demo : le glyphe « 0 » porte un filigrane « demo font sider.com ».
Ne jamais utiliser cette police pour un texte contenant des chiffres.

Jeu de caractères : espace, virgule, point, chiffres, A-Z, a-z. Aucun accent,
aucune ponctuation française. Les signes manquants s'affichent en bloc plein.

Conclusion : cette police ne sert qu'au LOGOTYPE (un fichier image), et
uniquement pour le mot « XILI » sans chiffres ni ponctuation. Pour tout le
reste — interface, documents, console, messages — il faut une police libre.

### 5.1 — BINAIRE VALIDÉ : Inter + JetBrains Mono (décision 2026-10-29)

- Interface : **Inter** — x-height 55 % (contre 52 % pour les candidats
  concurrents Plex), accentuée. Choix du « readable avant pretty ».
- Mono : **JetBrains Mono** — x-height 55 %, zéro pointé, `l` à patte, `I` à
  empattements. Le terminal est un citoyen de première classe (§5).
- Sous-ensembles livrés : `assets/fonts/inter-latin.woff2` (117 Ko),
  `assets/fonts/jetbrainsmono-latin.woff2` (46 Ko) + licences OFL.
- Sources complètes (travail) : `xili-design/fonts-evaluation/`.

Règles d'usage issues de l'évaluation :

1. Une icône d'interface se dessine en SVG — les glyphes `✕`, `⤢`, `≡` ne
   sont pas dans Inter/JetBrains Mono. Le prototype utilise désormais des
   SVG pour les contrôles de fenêtre.
2. Le texte courant n'emploie que des caractères couverts par les
   sous-ensembles (accents FR, ponctuation, opérateurs). Vérifié : OK.
